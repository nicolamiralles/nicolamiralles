## AlyxIA Solutions

**[alyxia.ch](https://alyxia.ch)** · *Co-fondateur · Startup étudiante de 10 personnes · 2026*  
→ Médaille de bronze au **Salon International des Inventions de Genève 2026**

Une plateforme d'IA générative **100 % locale** pour les PME : le modèle tourne sur un serveur GPU dans l'entreprise, donc les données sensibles ne quittent jamais ses locaux. Le MVP comprend un chat client, un chat administrateur et un backoffice avec un monitoring de la machine en temps réel, le tout accessible en HTTPS depuis le réseau local.

| Couche | Technologies | Rôle |
|:---|:---|:---|
| **Modèle IA** | Qwen3.6-35B-A3B (Mixture of Experts) | Modèle open-source déployé en local |
| **Inférence** | vLLM sur GPU NVIDIA | API compatible OpenAI, batching continu, streaming |
| **Backend** | Python · FastAPI · Uvicorn · Pydantic · httpx | API de chat, réponses en streaming SSE, gestion des conversations |
| **Données** | PostgreSQL | Conversations, messages et projets |
| **Authentification** | Keycloak · OIDC/PKCE | Login, rôles et sessions, avec un thème de connexion personnalisé |
| **Serveur web** | Nginx · HTTPS | Reverse proxy, point d'entrée unique, ports internes masqués |
| **Infrastructure** | Docker · Linux (Ubuntu) · Bash | Services isolés en conteneurs, script de démarrage automatisé |
| **Monitoring** | Serveur Python maison | État CPU, RAM, GPU et vLLM en JSON pour le backoffice |
